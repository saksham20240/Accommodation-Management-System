# Accommodation Management System

This is a simple C++ project made for managing rental accommodations. The project was created to practice object-oriented programming concepts and understand how real-world systems can be designed using classes and inheritance in C++.

The system allows users to add flats, display accommodation details, sort properties according to rent, and search for available accommodations. The project also uses STL vectors, lambda functions, and smart pointers to make the implementation cleaner and more efficient.

To compile the program:

```bash
g++ program_main.cpp -o app
```

To run the program:

```bash
./app
```

The project mainly demonstrates concepts like inheritance, polymorphism, abstract classes, encapsulation, STL containers, and memory management using `unique_ptr`.
